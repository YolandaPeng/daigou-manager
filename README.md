# 代购管理 Pro

这是一个静态网页代购管理工具，可部署到 GitHub Pages / Vercel / Netlify。

## 本版新增

1. 批量新增需求：一次可粘贴多行，不再只能一次录入一个顾客一个商品。
2. 批量登记已购买：例如一次买了 10 个面膜、5 个棉片、6 个洗面奶，直接按行登记，系统自动分配到未完成需求。
3. 小票图片：批量购买时可上传小票图片，图片会压缩后保存在浏览器本地。
4. 待买清单筛选：可按购买地查看待买清单。

## 数据模型

- demands：顾客需求记录，一行表示一个顾客的一种商品需求。
- purchases：购买批次记录，一行表示一次采购中的一种商品。
- 已买数量不是手填在需求里，而是由购买批次自动分配计算。

## 匹配规则

购买记录会匹配商品名相同的需求；如果购买记录里填写了规格、购买地、商品类目，则这些字段也必须一致。购买数量按照需求创建顺序分配。

## 使用建议

- 商品名、规格、购买地尽量使用固定写法，比如“面膜”不要有时写“面膜10片”、有时写“补水面膜”。规格可以单独写在规格备注里。
- 小票图片会占用浏览器本地存储空间，建议只上传关键小票，并定期导出 JSON 备份。
- 云端多人同步版本需要接数据库，例如 Supabase / Firebase。
